# paul-martin-web

Сайт магазина мужской одежды **Paul Martin** (Ташкент) — MVP для показа клиенту.
Статический сайт на Next.js: без бэкенда, базы данных и админки. Два языка — русский и узбекский.

## Что внутри

- **Главная:** три вертикальных фильма коллекции на первом экране (на телефоне идут друг за другом, как истории),
  категории, новая коллекция FW 26/27, блок Smart casual, распродажа −50%, backstage-видео, два магазина.
- **Каталог:** вкладки категорий, «Новинки», «Распродажа», фильтры по цвету и размеру, сортировка по цене, вид 4 / 3 / 2 в ряд.
- **Карточка товара:** галерея с отдельной прокруткой, просмотр фото на весь экран, другие цвета модели,
  выбор размера, таблица размеров, «другие модели».
- **Lookbook** с видео образов, **магазины**, **избранное** (хранится в браузере), **поиск**.
- **Корзина временно отключена:** «В корзину» открывает панель «Онлайн-заказ скоро откроется»
  с кнопками «Написать в Telegram» и «Позвонить».

Адреса: `/ru/...` и `/uz/...`. Корень сайта открывает язык, который посетитель выбирал раньше (по умолчанию русский).

## Запуск

```bash
npm install
```

```bash
npm run dev
```

Сайт откроется на http://localhost:3000/ru/.

## Где менять содержимое

| Что | Файл |
| --- | --- |
| Телефон, адреса магазинов, Instagram, Telegram | `src/data/site.ts` |
| Ссылка для кнопок «Написать в Telegram» | `src/data/site.ts`, поле `telegram` (пока пустое) |
| Товары, цены, размеры, описания (RU и UZ) | `src/data/products.ts` |
| Тексты интерфейса | `src/i18n/ru.ts`, `src/i18n/uz.ts` |
| Цвета и шрифт | `src/app/globals.css`, блок `@theme` |
| Ролики первого экрана | `src/components/Hero.tsx` |

**Цены — демо-значения**, придуманы для показа. Узбекские тексты стоит вычитать носителю языка.

## Фото, видео и логотип

- `source/telegram-export/` — экспорт Telegram-канала, который прислал магазин (исходники фото).
- `source/stills/` — кадры, вырезанные из видео (для бежевой куртки и кофейного свитера нет отдельных фото).
- `scripts/build-media.py` — обрезает фото до 4:5 и кладёт WebP в `public/media/p/`:

```bash
python3 scripts/build-media.py
```

- `public/media/film-*.mp4` — ролики из Telegram, ужатые для сайта, без звука и без финальной заставки.
- `src/brand/*.svg` — логотип, векторизованный с фото вывески. Если у магазина есть исходный вектор, замените эти файлы.

## Публикация

Каждый push в `main` собирает сайт и публикует его на GitHub Pages:
`https://<владелец>.github.io/paul-martin-web/`.

Один раз нужно включить: Settings → Pages → Source → «GitHub Actions».

Проверить сборку локально:

```bash
npm run build
```
